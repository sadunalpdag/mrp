# Telegram trading settings

In the configured Telegram chat, send `/limit 15` to set the daily maximum entry attempts and `/tutar 100` to set the maximum USDT position notional for NEW entries. Leverage remains 10x (100 USDT notional is about 10 USDT margin). `/otomatik_durum`, `/limit`, or `/tutar` displays the current settings.

Supported ranges: daily limit 1–15 (integer), position notional 1–100 USDT. Exchange minimum order filters still apply. Defaults remain 5 entries and 50 USDT until commands change them. `/sayac N` changes the USED daily count; `/limit` does not reset it. Lowering the limit below the used count blocks further entries. Concurrent occupancy defaults to five unique symbols. `/sembol 15` sets the shared open-position and pending-entry limit to 15 (allowed integer range 1–15). Closing TP orders are excluded. Lowering the limit does not cancel orders or close positions, but prevents new entries while occupancy is at or above the limit. This setting is saved alongside daily limit and notional. Existing positions and pending orders are not resized or canceled. TP and SL behavior is unchanged.

Settings are saved in crash_night_state.json and restored on restart if that file survives. Without persistent storage, a deploy can restore defaults; check `/otomatik_durum` after deploy. Commands retain configured-chat, freshness and forwarded-message checks. No live Binance requests are required for changing settings.
